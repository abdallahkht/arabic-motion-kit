# Sound effects | مكتبة الأصوات

80 WAV files. Drag a file into an editor, or use its filename without the extension as the scene’s `sound`. Set `soundAt` to the offset in seconds within that scene.

| المجموعة | العدد | أمثلة للاستخدام |
| --- | --- | --- |
| Keyboard | 20 | ظهور أمر في الطرفية، بحث، كتابة كابشن |
| Paper | 10 | تقليب صفحة أو كشف بطاقة جديدة |
| Interface | 20 | ضغط زر، تغيير خيار أو ظهور قائمة |
| Objects and movement | 22 | حركة قماش، خطوات، نقود أو قفل معدني |
| Synthesized accents | 8 | انتقال سريع، ظهور رقم أو تأكيد خطوة |

For an on-screen search, try `typing-01`. For a page transition, try `page-turn-03`. Match the sound to the action and leave room for the voice.

## Sources

The eight synthesized accents are generated by this kit. The other 72 files are selections from four CC0 collections, converted to 48 kHz mono PCM WAV. [Filename, duration and source for each cue](catalog.json).

- StarNinjas · [book flips - starninjas](https://opengameart.org/content/10-book-page-flips)
- Unicae Games · [unicae games keyboard soundpack 1](https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes)
- Kenney · [UI SFX Set](https://opengameart.org/content/51-ui-sound-effects-buttons-switches-and-clicks)
- Kenney · [RPGsounds Kenney](https://opengameart.org/content/50-rpg-sound-effects)
