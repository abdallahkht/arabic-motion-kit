# Arabic Motion Kit

Read README.md for setup and select the matching skill: skills/animate/SKILL.md, skills/explain/SKILL.md or skills/video-fx/SKILL.md. Follow the member's existing editing style. Work in a new project folder; preserve sources and previous versions. Never publish personal media automatically.
